# بناء ملف APK للأندرويد (من غير Android Studio)

1. أنشئ حساب مجاني على github.com ثم مستودع جديد (Repository) باسم studio.
2. ارفع كل محتويات هذا المجلد (بما فيها مجلد .github) على المستودع.
3. ادخل تبويب Actions ثم Build APK ثم Run workflow، وانتظر 5-8 دقائق.
4. افتح التشغيلة المكتملة ونزّل studio-apk ثم فك الضغط وثبّت app-debug.apk على الهاتف (اسمح بالتثبيت من مصدر غير معروف).

# تشغيل السيرفر
شغّل مجلد studio-server على جهاز كمبيوتر أو سيرفر، وفي التطبيق اكتب عنوانه
(مثال: http://192.168.1.10:8000) داخل خانة عنوان السيرفر. الهاتف والكمبيوتر على نفس الشبكة.
